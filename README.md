# Greeting Card

A simple Android application created as part of the [Android Basics with Compose](https://developer.android.com/courses/android-basics-compose/course) course.

This project follows the [Your first Android app](https://developer.android.com/codelabs/basic-android-kotlin-compose-first-app) codelab.

## Features
- Built with **Jetpack Compose**.
- Demonstrates basic UI components: `Text` and `Surface`.
- Uses **Material Design 3** theming.
- Includes a Composable function with a Preview.

## Learning Objectives
- Understanding the basic structure of an Android project.
- Introduction to Jetpack Compose and Declarative UI.
- Working with Composables and Modifiers.
- Using Android Studio's Preview functionality.

## How to Run
1. Open this project in **Android Studio**.
2. Run the `app` module on an emulator or a physical device.
3. You can also view the UI directly in Android Studio using the **Preview** tab in `MainActivity.kt`.
